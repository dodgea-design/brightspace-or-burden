## Upload to GitHub

1. Open the `brightspace-or-burden` repository.
2. Select the existing `index.html` file.
3. Choose **Add file > Upload files** or use the repository's replacement workflow.
4. Upload this updated `index.html` at the repository root.
5. Confirm that GitHub shows `index.html` as changed, then commit the change.
6. Wait a minute or two and refresh the Sources page with a hard refresh (`Ctrl+F5` on Windows).

Do not delete or replace the `assets` folder, `styles.css`, or `app.js` for this update.
